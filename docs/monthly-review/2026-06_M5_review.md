## 3. 学到的关键概念

> 月末填写时把每条写成「能给同事讲 3 分钟」的版本，不超过 3 句。

1. **「weight shift = 防前视的物理基础」**：`weights[t]` 的语义必须是「`t` 时刻末已知，赚 `t→t+1` 的收益」。引擎内部 `weights.shift(1)` 是这个约定的唯一实现入口；离开引擎自己拼乘法 99% 会写错（演示见陷阱 1：Sharpe 从 -0.4 → 66.5）。
2. **「成本必须显式」**：把 `cost_bps=None` 设为默认值并在引擎构造函数里抛错。「忘了加成本」是回测里最常见的诚实问题，编译器是最好的纪律官。

## 4. 踩过的坑

- **浮点精度污染 Sharpe**：constant return series 的 `std()` 不是真正的 0，而是机器 epsilon 量级；按 `> 0` 判断会算出 7e16 的 Sharpe。修复：用相对均值绝对值的 `vol_floor = 1e-12 * max(|mean|, 1e-6)`。已写测试 `test_constant_positive_return_zero_volatility` 守住。
