## 2. 踩过的坑与经验教训
- **数据对齐陷阱**：在计算 RSI 和 ATR 时，平滑算法（如 Wilder's Smoothing）如果不手动通过 `ewm` 调整 `min_periods` 以及丢弃前 N 个不稳定的值，很容易导致早期的指标数值污染，引发前视误差或与标准库不一致。
- **协整与相关性的区分**：两条走势高度相关的价格曲线（如 SPY 和 QQQ）并不代表存在协整关系；真正的协整要求它们的线性组合（价差）是**平稳的**（均值回归）。这是配对交易最核心的假设。
