# 策略报告：`momentum_us_monthly_top20`

> 横截面动量（Jegadeesh & Titman 1993）的"12-1"经典构型：每月按过去 12 个月
> （剔除最近 1 个月）收益排序，多头前 20% / 空头后 20%，等权、月度调仓。

| 字段 | 值 |
|---|---|
| 类型 | 横截面动量（cross-sectional momentum），美股风格 |
| 信号 | `lookback=252, skip=21`（12-1），`close.shift(21).pct_change(252)` |
| 仓位 | 多空各 20% 等权，dollar-neutral，`gross=1.0`（多 0.5 / 空 0.5） |
| 调仓 | 月度（月末权重 ffill 保持，成本 ~12×/年） |
| 成本 | 10 bps/side（美股大盘流动性） |
| 实现 | `quant_lucky.strategies.momentum` + `…risk_parity.hold_between_rebalances` |
| 复现 | `python strategies/momentum_us_monthly_top20/run_backtest.py` |

---

## 1. 理论来源

Jegadeesh & Titman (1993) 发现美股 3–12 个月的"赢家"在随后数月继续跑赢"输家"，
是金融学被重复验证最多的异象之一。剔除最近 1 个月（skip）是为了避开短期反转
（short-term reversal）对信号的污染——故称"12-1 动量"。dollar-neutral 的多空结构
把横截面信号从市场方向中剥离出来，目标 beta ≈ 0。

## 2. ⚠️ 数据诚实性（本报告最重要的一节）

**离线环境拿不到标普 500 全成分横截面**（本仓库有 yfinance 429 限频的历史记录），
缓存里的少数美股名字无法构成 500 名的可排序横截面。因此本策略跑在**合成面板**上，
运行时自报 `data: synthetic`。

合成面板默认使用**同质期望收益**（`drift_dispersion=0, beta=1`），所以在
`autocorr=0` 时它是一个**真正的零假设（null）**：动量排序的是纯粹的特异性噪声，
理应赚 ≈0。这一节的全部数字都在验证**流水线与诚实性信号**，**不是**一个被发现的 Alpha。

> **构建本策略时踩到并留档的坑**：若用 generator 的*异质*默认值（drift/beta 离散），
> 动量排序会在 `autocorr=0` 时仍跑出 **Sharpe ≈ 2.5** 的*假*结果——它机械地收割了
> generator 写死的静态截面离散度（"赢家"持续赢只因为它们的真实 drift 被固定且被回测
> "偷看"到了）。这正是 M5/M6 的核心教训：**回测可以因为不可交易的理由而好看**。
> 详见 `docs/pitfalls.md` 2026-06 条。

## 3. 回测结果（零假设：`autocorr=0`，净费后）

| window | ann_return | ann_vol | sharpe | max_dd | hit_rate |
|---|---:|---:|---:|---:|---:|
| full | 0.32% | 4.04% | **0.08** | -7.81% | 41.5% |
| in-sample | 0.34% | 3.79% | 0.09 | -7.81% | 37.9% |
| out-of-sample | 0.28% | 4.56% | **0.06** | -6.04% | 49.8% |
| benchmark（等权多头） | 13.01% | 16.28% | 0.80 | -26.06% | 50.4% |

**读法**：full Sharpe 0.08、OOS 0.06——在零假设面板上动量赚不到钱。这是**正确的**结果。
年化单边换手 4.38。

## 4. 稳健性测试

### 4.1 Walk-Forward + DSR（参数泛化）

- 8 个滚动窗口（train 504 / test 126），32 trials；
- 聚合 OOS Sharpe **0.19**；
- **Deflated Sharpe Ratio = 0.000**——在 32 次试验的多重检验噪声下，真实 Sharpe > 0
  的概率约等于 0。

**读法**：DSR ≈ 0 把"我扫了 4 个 lookback 总有一个 OOS 好看"这件事的水分挤干了。
这正是 DSR 存在的意义。

### 4.2 参数敏感性（±50% 重跑，OOS Sharpe）

| param | value | full_sharpe | oos_sharpe | is−oos |
|---|---|---:|---:|---:|
| lookback | 126 | -0.04 | -0.25 | 0.31 |
| lookback | 189 | 0.10 | 0.45 | -0.53 |
| lookback `*` | 252 | 0.08 | 0.06 | 0.03 |
| lookback | 315 | -0.22 | -0.69 | 0.73 |
| skip | 0 | 0.60 | 0.51 | 0.14 |
| skip `*` | 21 | 0.08 | 0.06 | 0.03 |
| top_quantile | 0.1 | 0.41 | 0.90 | -0.77 |
| top_quantile | 0.3 | 0.38 | -0.25 | 0.95 |

**读法**：OOS Sharpe 在 0 附近无规律地上下跳（-0.69 → +0.90），没有任何参数邻域是稳定
为正的——典型的"噪声地形"。`skip=0` 略高是因为短期反转在合成噪声里偶然帮了忙，并非
真实效应。

## 5. 归因（对等权市场基准的单因子 OLS）

- Beta **-0.002**，年化 alpha **0.34%**，相关性 -0.007（R² 0.000）。

**读法**：beta ≈ 0 证明 dollar-neutral 构造确实做到了市场中性——策略的（近零）收益既不是
靠市场 beta，也没有 alpha。这正是我们希望归因能*证明*的事。

## 6. 机器能抓到边吗？植入边演示（`--set synthetic.autocorr=0.12`）

往面板注入真实的趋势持续性后，**同一套机器**立刻抓住它：

| window | ann_return | sharpe | max_dd | | WF 聚合 OOS Sharpe | DSR |
|---|---:|---:|---:|---|---:|---:|
| full | 13.96% | **3.45** | -2.49% | | **4.77** | **1.000** |
| out-of-sample | 15.23% | 3.36 | -2.49% | | | |

归因：beta -0.001、年化 alpha **13.99%**——依然市场中性，收益全部来自横截面信号。
DSR 从 0.000 跳到 1.000：当边真实存在时，多重检验折扣挡不住它。

**这才是本策略的真正交付物**：一条"零假设 → DSR≈0；有真边 → DSR≈1"的完整可信链路，
而不是一个声称发现了动量 Alpha 的数字。

## 7. 局限性

1. **合成数据**：对真实动量的幅度/衰减不做任何断言；只验证方法学。
2. **做空理想化**：未建模融券成本、可借券约束、轧空风险。
3. **等权腿忽略容量**：真实标普动量受容量约束，且有"动量崩溃"尾部风险（2009）。
4. **月末调仓的日历效应**未建模（真实存在 month-end 拥挤）。
