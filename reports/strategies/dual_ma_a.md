# 策略报告：`dual_ma_a_daily_vol_filter`

> 双均线交叉 + 波动率过滤的趋势跟踪（A 股）。快线（20 日）上穿慢线（60 日）**且**
> 实现波动率低于上限（年化 40%）时持有，否则空仓。Long-only——A 股零售难做空。

| 字段 | 值 |
|---|---|
| 类型 | 趋势跟踪（Kaufman），A 股，long-only |
| 信号 | `fast=20, slow=60`；持有 ⟺ `MA20 > MA60` 且 `realised_vol(20) ≤ 40%` |
| 仓位 | budget-per-name：开闸 `1/N`，否则现金（gross 随合格名数下降） |
| 调仓 | 日频信号，仅在开闸/关闸切换时交易 |
| 成本 | 30 bps/side（A 股印花税 0.05% 仅卖方 + 佣金/过户，对称化保守值） |
| 数据 | 8 只缓存 A 股蓝筹（akshare 日线，**2022-01 → 2023-12**，484 个交易日） |
| 复现 | `python strategies/dual_ma_a_daily_vol_filter/run_backtest.py` |

---

## 1. 理论来源

趋势系统在持续单边行情中获利，在震荡/均值回归行情中亏损。双均线交叉定义趋势方向；
波动率过滤是一个**regime 闸门**——在波动过大（最易来回打脸 whipsaw）的名字上直接空仓。
预算-按名（budget-per-name）权重让 gross 敞口在合格名变少时**下降**，这是过滤器应有的
防御行为，而"始终满仓"的归一化会把它藏起来。

## 2. 数据（真实）

8 只跨行业流动性蓝筹（茅台/招行/平安/恒瑞/美的/伊利/平安银行/浦发），按共同交易日
inner-join。**这是一个小样本、短窗口、且对趋势极不友好的 regime**——足以在真实数据上
演示策略与评测框架，但**不足以**得出关于 A 股趋势跟踪的总体结论。沪深 300 全历史（含退市）
是 M6 遗留数据任务。

## 3. 回测结果（净费后）

| window | ann_return | ann_vol | sharpe | max_dd | hit_rate |
|---|---:|---:|---:|---:|---:|
| full | -6.18% | 7.23% | **-0.85** | **-14.49%** | 33.7% |
| in-sample | -3.91% | 7.07% | -0.55 | -8.66% | 29.9% |
| out-of-sample | -11.42% | 7.60% | -1.50 | -9.02% | 42.5% |
| benchmark（等权买入持有） | -7.29% | 19.77% | -0.37 | **-30.79%** | 43.2% |

**读法**：2022–2023 A 股震荡下行，等权基准买入持有就亏了 -7.3%/年。Long-only 趋势策略没有
上涨趋势可骑，**亏了一点钱**——但它**亏得很克制**：最大回撤 -14.5% 仅为基准 -30.8% 的一半，
年化波动 7.2% 约为基准 19.8% 的三分之一。它靠在下跌段**空仓**实现了这种防御。

## 4. 稳健性测试

### 4.1 Walk-Forward + DSR

- 4 个滚动窗口（train 252 / test 63），12 trials；
- 聚合 OOS Sharpe **-1.93**，**DSR = 0.000**。

**读法**：DSR ≈ 0 = 在这个窗口里**没有统计意义上的边**。这是诚实的结论，不是一个可上线的
策略。趋势跟踪需要趋势，而这段样本没有。

### 4.2 参数敏感性（OOS Sharpe）

| param | value | full_sharpe | oos_sharpe |
|---|---|---:|---:|
| fast | 10 / **20** / 30 | -0.95 / -0.85 / -1.06 | -2.40 / -1.50 / -1.29 |
| slow | 40 / **60** / 90 | -1.04 / -0.85 / -0.65 | -1.70 / -1.50 / -1.13 |
| vol_max | 0.3 / **0.4** / 0.5 / off | -1.35 / -0.85 / -0.99 / -0.91 | -1.56 / -1.50 / -1.56 / -1.55 |

**读法**：**全网格一致为负**——没有任何参数组合能在这个 regime 里赚钱，这反而让结论可信
（不是挑了个倒霉参数）。慢线越长（90）亏得越少，符合"更钝的趋势过滤在震荡市里交易更少"
的直觉。

### 4.3 波动率过滤有用吗？（filter on vs off）

| | full Sharpe | max_dd | 年化换手 |
|---|---:|---:|---:|
| filter **on**（vol_max=0.40） | **-0.85** | **-14.49%** | 4.95 |
| filter **off**（纯双均线） | -0.91 | -16.47% | 4.56 |

**读法**：过滤器边际有用——更高的 Sharpe、更浅的回撤，符合"在高波动名字上空仓避开
whipsaw"的设计意图（代价是换手略升）。

## 5. 归因（对等权基准的单因子 OLS）

- Beta **0.210**，年化 alpha **-4.65%**，相关性 0.574（R² 0.330）。

**读法**：beta 仅 0.21——因为 long-only 趋势策略大量时间在现金，对篮子的净多头敞口很低。
负 alpha 说明择时（进出场）在这段震荡市里是减分的（cost drag + whipsaw）。策略的价值在
这段样本里**不是收益**，而是把 beta 敞口和回撤压到基准的一半以下。

## 6. 局限性

1. **小篮子、短窗口、单一（对趋势不利的）regime** → 不具代表性。
2. **未建模 A 股 T+1、±10% 涨跌停撮合约束、停牌**（向量引擎假设收盘价成交）。
3. **对称成本忽略买卖印花税不对称**（印花税仅卖方 0.05%）——对买入偏悲观、对卖出偏乐观。
4. budget-per-name 在 8 名小篮子上单名权重高（1/8），分散不足。

## 7. 结论

一个**诚实的负结果**：策略在 2022–2023 A 股做了趋势策略该做的事——在没有趋势时克制地
de-risk（半个回撤、三分之一波动），但 cost+whipsaw 仍带来小幅亏损，DSR=0 确认无统计边。
要判断它是否真有效，需要在含上涨 regime 的更长样本（沪深 300 全历史）上重测。
